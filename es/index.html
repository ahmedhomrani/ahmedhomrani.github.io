SmartDigiDocs

Una plataforma en la nube con sede en Bruselas que automatiza la creación, distribución y firma electrónica de documentos personalizados para bancos, aseguradoras, equipos de RR. HH. y administraciones. Trabajo en su núcleo Java: estándares, pagos y seguridad.

  • Arquitectura de servicios multi-tenant con OAuth2, SAML y JWT: control de acceso RBAC/ABAC, registros de auditoría consolidados y modelo zero-trust entre clientes.
  • Auditorías de seguridad SAST y DAST automatizadas en los pipelines de Jenkins y Azure DevOps.
  • Autenticación y gestión de accesos de Active Directory mediante JNDI Realm y LDAP.

Tabibi, plataforma de salud digital

Tabibi.tn ayuda a los pacientes de todo Túnez a encontrar un médico, dentista, laboratorio o farmacia y a reservar cita en línea. Los médicos tienen su propio espacio para gestionar citas e historiales.

  • API REST en Spring Boot con autenticación JWT, control de acceso por roles y HTTPS.
  • App en Flutter para iOS y Android: citas e historiales médicos al alcance del móvil.
  • Capa de persistencia con Spring Data JPA optimizada para datos médicos complejos bajo carga concurrente.
  • Notificaciones en tiempo real para recordatorios de citas y confirmaciones de reserva.

Sobre mí

Soy desarrollador Java e ingeniero de software, con base en Túnez, con tres años de experiencia profesional en Java y Angular. Me importan la Clean Architecture y las partes discretas del software: la regla de validación que frena una factura errónea, el control de acceso que impide a un cliente ver los datos de otro, la consulta SQL que hace que un informe cargue en segundos.

Terminé un máster en desarrollo de software mientras trabajaba, y uso herramientas de desarrollo con IA a diario. Algo sobre mí: no puedo dormir si queda un bug en mi proyecto.
